# v1.0.0-beta readiness

> **Historical v1.0.0 beta release record.** Statements below describe their original baseline,
> not the current deployed feature set or remaining release gates. Original
> content is retained for traceability. See [current state](../current-state.md) for v2.0.3
> and links to current acceptance and release evidence.

The beta ships when every gate below is checked. Gates are split by who can
close them: code gates are closed in this repository; field gates need real
borrowers and real bank paperwork; operator gates need credentials and a
decision.

## Code gates — closed
- [x] Engine `plan/2`: dated portfolio simulator, typed refusals, cash
      conservation, search certificate, proven-optimal path (PR #51).
- [x] Golden corpus provenance ratchet and mid-life anchors (#52, #53).
- [x] Plans are approvable and stored; the sheet renders the whole
      repayment with per-loan rows and freed instalments (#65, #76).
- [x] Reminders wired end to end; a reminder covers its whole day (#62, #76).
- [x] Mini App: modular, edge-served, version-addressed immutable assets,
      esbuild CI gate on the module graph (#66, #74, #77).
- [x] Cross-architecture determinism in CI; cache keyed by contract
      fingerprint (#62).
- [x] Journey tips, refusals with fixing buttons, reliability caveats.

## Ship mechanics (already wired)
- Tagging `v1.0.0-beta` runs the release workflow (build, compat check,
  GitHub prerelease) and `CD · prod`, which deploys only once the operator
  gates above are closed — an unarmed run fails at the first missing
  secret, by design.
